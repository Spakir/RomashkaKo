# Документация API

## Введение

Данная документация описывает доступные конечные точки API для проекта "МоиТовары".

## Базовый URL

http://localhost:8080/api

## Конечные точки

### 1. Создание товара

- **Метод:** 'POST'
- **URI:** `/product/`
- **Описание:** Создает новый товар.
- **Тело запроса:**
- ```json
   {
    "name" : "Товар 1",
    "description" : "Описание",  
    "price" : 100,
    "inStock" : true 
   }
    ```
- **Ответ:**
- **Код: 200 ОК**

### 2. Получение списка товаров

- **Метод:** 'GET'
- **URI:** `/product/`
- **Описание:** Получает список всех товаров.
- **Ответ:**
- **Код: 200 ОК**
- **Тело ответа:**
- ```json
    [
      {
          "id" : 1,
          "name" : "Товар 1",
          "description": "Описание товара 1",
          "price" : 100,
          "inStock" : true 
      },
      {
          "id" : 2,
          "name" : "Товар 2",
          "description": "Описание товара 2",
          "price" : 200,
          "inStock" : true 
      }
    ]
    ```

### 3. Получение товара по ID

- **Метод:** 'GET'
- **URI:** `/product/{id}`
- **Описание:** Получает товар по ID.
- **Параметры пути:**
  - `id` (число,обязательный) - ID товара,который нужно получить 
- **Ответ:**
  - **Коды:** 
    - **Код: 200 ОК**
    - **Код: 404 Not Found** (если товар не найден)
- **Тело ответа (при коде ответа 200):**
- ```json
   {
    "id" : 1,
    "name" : "Товар 1",
    "description" : "Описание",  
    "price" : 100,
    "inStock" : true 
   }
    ```
- **Тело ответа (при коде ответа 404):**
- ```json
   {
     "timeStamp": "2025-01-18T09:36:07.5393874",
     "errorMessage": "Товар с данным id не был найден"
   } 
   ```
  
### 4. Обновление товара по ID

- **Метод:** 'PUT'
- **URI:** `/product/{id}`
- **Описание:** Обновляет товар по ID.
- **Параметры пути:**
  - `id` (число,обязательный) - ID товара,который нужно обновить
- **Тело запроса:**
- ```json
     {
      "name" : "Товар 1",
      "description" : "Новое описание",  
      "price" : 100,
      "inStock" : true 
    }
  ```
- **Ответ:**
  - **Коды:** 
    - **Код: 200 ОК**
    - **Код: 404 Not Found** (если товар не найден)
- **Тело ответа (при коде ответа 404):**
- ```json
   {
     "timeStamp": "2025-01-18T09:36:07.5393874",
     "errorMessage": "Товар с данным id не был найден"
   } 
   ```
### 5. Удаление товара по ID

- **Метод:** 'DELETE'
- **URI:** `/product/{id}`
- **Описание:** Удаляет товар по ID.
- **Параметры пути:**
  - `id` (число,обязательный) - ID товара,который нужно удалить
- **Ответ:**
  - **Коды:**
    - **Код: 200 ОК**
    - **Код: 500 Internal Server Error**
- **Тело ответа (если код 500):**
- ```json
    {
     "timeStamp": "2025-01-18T09:36:07.5393874",
     "errorMessage": "Не удалось удалить товар"
    } 
  ```
